# 헤리티지 캐러셀 레이아웃 그래머 v2 (2026-08-03)

근거: 매거진 B 서사 구조 리서치 + 에디토리얼 레이아웃 변주 리서치 (docs/audit-2026-08-03.md와 세트)

## 설계 원칙 (총량제 — Cereal 모델)

- **그리드 1개**: 모든 카드 동일 외곽 마진(8.2cqw) 위에서만 변주. 분할선·정렬선은 같은 컬럼 라인에 스냅.
- **타입 스타일 6개 제한**: 세리프 1(Display/Head) + 산세리프 1(Jost) 조합으로 Display·Headline·Body·Caption·Label·Folio만 사용. 카드마다 새 크기 발명 금지.
- **톤 3개**: 다크(팔레트) / 페이퍼(웜 아이보리) / 브랜드 악센트 1색.
- **미세 시그니처 고정**: 페이지 폴리오(`N — 08`)와 시리즈명(`BRAND HERITAGE`)을 8장 전부 같은 좌표·같은 크기로. 마스트헤드 가로 선(border) 전면 제거.
- **로고**: 커버 + 콜로폰 2회만. 본문 카드는 텍스트 시그니처로 대체.
- **이미지 1장 = 1회**: 세트 내 originalId 중복 금지(기존 가드 유지) + 브랜드 간 전역 레지스트리(1 이미지 = 1 브랜드).
- Creative Curve: 익숙함 80% = 고정 그리드·타입·팔레트·시그니처 / 신선함 20% = 카드마다 바뀌는 아키타입.

## Series A — "매거진 B 아크" (기본값, 이번 시안)

매거진 B의 핵심: 정보를 앞세우지 않는다. 무드 → 오브젝트 → 사람 → 검증 → (전환부) 역사 → 디테일 → 수미상관.

| # | 씬 (기존 key) | 아키타입 | 이미지 비율 | 역할 |
|---|---|---|---|---|
| 1 | cover | 풀블리드 매거진 커버 (기존 12종 변주 유지) | 100% | 起 · B's Cut — 한 장이 브랜드 전체를 말한다 |
| 2 | heroshot | **풀블리드 포스터** (커버와 같은 계열, 워드마크 소형+한 줄) | 100% | 起 · Impression — 무드 확장 |
| 3 | product | **플레이트(라이트)** — 페이퍼 배경 + 오브젝트 45~55% + 뮤지엄 라벨 캡션 | 50% | 承 · The Object |
| 4 | founder | **비대칭 스플릿** — 상단 62% 초상 + 하단 좌정렬 텍스트 | 60% | 承 · The Person |
| 5 | quote | **타이포 온리 풀퀘이트** — 이미지 0, 대형 세리프 인용 | 0% | 承→轉 · 제3자/창업자의 목소리 |
| 6 | heritage | **에세이(드롭캡)** — 텍스트 밀도 최대, 반전 서사 | 0~15% | 轉 · Brand Story (역사는 여기, 앞이 아니라) |
| 7 | behind | **디테일 크롭** — 소재·공정 클로즈업 풀블리드 + 캡션 한 줄 | 100% | 轉→結 · 크래프트 크레센도 |
| 8 | closing | **콜로폰** — 크레딧·시리즈 인덱스·로고·다음 회차 티저 | 30% | 結 · 카드 1과 수미상관 |

이미지 리듬: 100 → 100 → 50 → 60 → 0 → 0 → 100 → 30 (무드 존 → 오브젝트/사람 존 → 텍스트 존 → 크레센도 → 착지)

## Series B — "아카이브 도록" (2차, 제품 아카이브 풍부한 브랜드: watch/auto/camera)

커버 → 타임라인 인덱스 → 오브젝트 플레이트 → 뮤지엄 라벨(툼스톤) → 디테일 크롭 → 풀퀘이트 → 스플릿(현재의 브랜드) → 콜로폰

## Series C — "다크/라이트 교차" (2차, 다크 톤 원본 많은 브랜드: spirits/watch/hotel)
